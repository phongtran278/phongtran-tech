# phongtran.tech

Personal product lab for Phong Tran.

## Stack
- React + Vite + TypeScript
- Motion for interface animation
- GSAP installed for selective cinematic scroll sequences
- Data-driven project index

## Run
```bash
npm install
npm run dev
```

## Direction
The homepage is intentionally not a fixed “product universe”. It uses a scalable project index + dynamic preview so the lab can grow from 5 to 50+ products/experiments without redesigning the information architecture.
